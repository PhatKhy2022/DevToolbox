Build a modern frontend-only Developer Toolbox web application using Vue.js, TypeScript, and Tailwind CSS latest version.

The application should be a fast, clean, modern developer utility platform similar to DevUtils, JSON formatter tools

IMPORTANT REQUIREMENTS:

* Frontend only
* No backend
* No database
* Store everything in localStorage or IndexedDB
* Responsive design
* Dark mode support
* Beautiful UI 
* Use Zustand for state management

CORE FEATURES:

1. JSON Formatter

* Pretty print JSON
* Minify JSON
* Validate JSON
* Copy formatted JSON
* Download JSON file

2. CSV ↔ JSON Converter

* Upload CSV or xlsx
* Convert CSV to JSON
* Convert JSON to CSV
* Download converted file

3. YAML ↔ JSON Converter

* Parse YAML
* Convert YAML to JSON
* Convert JSON to YAML

4. JWT Decoder

* Decode JWT payload
* Show expiry time
* Copy payload

5. UUID Generator

* Generate UUID v4
* Generate multiple UUIDs
* Copy all UUIDs

6. Base64 Tool

* Encode text
* Decode text
* File support

7. Timestamp Converter

* Unix timestamp to readable date
* Date to timestamp
* Timezone support

ADVANCED FEATURES:

* Auto detect pasted content type
* Drag and drop upload
* Copy buttons everywhere
* Download output files
* Tool history in localStorage
* Saved snippets/workspaces
* Keyboard shortcuts
* Multi-tab workspace
